# StudyFree — Version 1

A simple responsive homepage for a free educational resources website.

## Files
- index.html — homepage
- style.css — design and responsive layout
- script.js — search, subject filtering, mobile menu

## Run locally
Double-click `index.html` to open it in a browser.

## Customize
1. Replace `your-email@example.com` in `index.html` with your real contact email.
2. Replace the placeholder video cards with your own/authorized YouTube embeds.
3. Add your lawful/open-licensed books and notes in later versions.

## Free publishing
This static site can be published using a free static hosting service such as GitHub Pages.
